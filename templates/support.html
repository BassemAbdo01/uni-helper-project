Nexora Sync

Help

Setting it up

  1. Install Nexora Sync from the Chrome Web Store.
  2. Click the Nexora icon in your toolbar, then Connect to Nexora. It opens Nexora and links itself to your account. There is no key to copy.
  3. Open your own university's Brightspace in a tab and sign in as normal.
  4. Click the Nexora icon again and press Import my courses. Chrome will ask permission for your university's address the first time.

Using Canvas instead?

There is no extension to install. Open Canvas in Nexora, paste your Canvas web address and an access token generated under Account → Settings → New Access Token, and press Connect.

If Canvas rejects the token, the usual cause is that it expired or was deleted under Approved Integrations. Generate a new one and paste it again.

If Canvas says your administrators have limited your ability to generate a token, you do not need one. Install the Nexora Sync extension, open Canvas, and press Import: it reads through the session you are already signed into. The only thing a token adds is syncing while your browser is shut.

If something is not working

"Open your Brightspace" will not go away

Nexora looks for a tab whose address contains /d2l/, which every Brightspace uses. Make sure you are signed in and looking at Brightspace itself rather than a university portal page that merely links to it.

Chrome never asked for permission

The request only appears while the Brightspace tab is the one in front. Switch to that tab, then open the Nexora popup and press Import again.

"Nexora Sync is not installed here"

The extension is installed in a different Chrome profile from the one you are signed into Nexora with. Use the same profile for both.

"Your Brightspace session expired"

Nexora reads Brightspace through your own sign-in, so when your university signs you out it stops too. Open Brightspace, sign in again, then sync.

No courses were found

Open your Brightspace My Courses page so the course list has loaded, then press Import again. If your term has not started, Brightspace may not be showing the courses yet.

A lecture will not summarise

Nexora needs the text of that file. Open the item in Brightspace once so it can be read, then try again. Scanned PDFs with no text layer cannot always be read; you can upload the file to Nexora directly instead.

Nexora only ever reads your LMS. It never submits work, posts, or changes anything, and it never sees your university password.
